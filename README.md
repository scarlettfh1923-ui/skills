# skills

两个中文非虚构写作 Skill，版本 v1.3.0。

| Skill | 用途 | 目录 |
|---|---|---|
| 人物传记与时代特稿写作（biographical-longform-feature） | 给一个或两个人物姓名，检索可靠史料，写成有叙事张力的非虚构人物长文 | `人物传记与时代特稿写作/SKILL.md` |
| 财经非虚构深度写作（finance-nonfiction-writer） | 给一个人物、公司、行业、城市、政策或事件，写成财经非虚构长文 | `finance-nonfiction-writer-skill/SKILL.md` |

两个 Skill 都包含事实核查、全文校对润色和责任编辑终审（只把关，不改作者文风），最终只交付含标题、正文和参考资料的 Markdown 文件，参考资料为不分类的连续编号列表，按 GB/T 7714 参照格式著录。
